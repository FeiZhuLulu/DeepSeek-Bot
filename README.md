# DeepSeek Bot

中文 | [English](README.en.md)

DeepSeek Bot（dsh-bot）是一个 [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness)（简称 DSH）插件，将 DSH Web、Desktop 转化为多智能体协作的形式（类似于 Grok Bot）。

它具有：

- 多智能体沟通协调
- 自定义 provider，不受单一订阅困扰（后续可能会增加使用 AI 订阅的支持）
- 多智能体并行工作，互不干扰
- 多智能体群聊（会非常消耗额度）
- 高度自定义功能

源码将在不久完全开源！谢谢你的支持。可以 Watch 或 Star 本仓库，开源时会在这里发布。
