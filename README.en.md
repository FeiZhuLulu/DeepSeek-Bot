# DeepSeek Bot

[中文](README.md) | English

DeepSeek Bot (dsh-bot) is a [DeepSeek Harness](https://github.com/deepseek-ai/deepseek-harness) (DSH) plugin that turns DSH Web and Desktop into a multi-agent collaboration workspace (similar to Grok Bot).

Features:

- Communication and coordination between multiple agents
- Custom providers, so you are not tied to a single subscription (support for using AI subscriptions may be added later)
- Multiple agents work in parallel without interfering with each other
- Multi-agent group chats (these use a lot of quota)
- Highly customizable

The source code will be fully open-sourced soon! Thank you for your support. Watch or star this repository; the release will be published here.
